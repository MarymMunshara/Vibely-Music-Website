🎧 Vibely — Music Discovery Website

Vibely is a modern, visually engaging, and fully responsive music discovery website created as a web development internship project. It is designed around the idea of discovering music according to your mood, exploring trending songs, finding artists, and browsing curated playlists.

✨ Features

🎵 Modern music discovery interface

🎨 Soft violet, pink, peach, and blue visual theme

🌙 Explore music by mood

🔥 Trending songs section

🎤 Popular artists section

🎧 Curated playlists

💿 Music player interface

🔍 Search interface

📩 Newsletter subscription section

🍔 Responsive mobile navigation

✨ Hover effects and CSS animations

📱 Fully responsive layout for desktop, tablet, and mobile

🛠️ Technologies Used

HTML5

CSS3

Google Fonts

CSS Grid

CSS Flexbox

CSS Animations

Responsive Web Design

🎨 Design

Vibely uses a soft, colorful, and premium visual style combining:

💜 Violet

🌸 Pink

🍑 Peach

💙 Blue

🤍 Soft neutral tones

The interface is inspired by modern music platforms while maintaining its own clean visual identity.

📱 Responsive Design

The website adapts to different screen sizes:

💻 Desktop

💻 Laptop

📲 Tablet

📱 Mobile

The layout, navigation, cards, typography, and music player adjust automatically for smaller screens.

🚀 How to Run

No installation is required.

Download or clone this repository.

Open the project folder in VS Code.

Open index.html in your browser.
